# Automotive SPICE Resources

## Knowledge

- [VDA QMC: _Automotive SPICE PRM/PAM 4.1 (Preview)_, 2026-04-16](https://vda-qmc.de/wp-content/uploads/2026/04/Automotive-SPICE-PAM-4.1_Preview.pdf)
  The primary source. Chapter 3 (pp. 13–27) is the whole model in miniature; chapter 4 has each process's purpose, outcomes and base practices; chapter 5 the process attributes and generic practices; Annex B the information items. Use for: every claim in every lesson. Page anchors (`#page=N`) match the printed page numbers.
- [VDA QMC: Automotive SPICE publications page](https://vda-qmc.de/en/automotive-spice/automotive-spice-veroeffentlichungen/)
  The only sanctioned download point for the PAM and its companions (Cybersecurity PAM, the Guidelines). Use for: checking which version is current.
- [VDA QMC: _Automotive SPICE PAM 4.0_ (2023)](https://vda-qmc.de/wp-content/uploads/2023/12/Automotive-SPICE-PAM-v40.pdf)
  The previous release, which most training material and the Guidelines 2.0 still target. Use for: comparing when a secondary source quotes 4.0.
- [VDA QMC: _Automotive SPICE Guideline_ (webshop, paid)](https://webshop.vda.de/QMC/en/automotive-spice-guideline-assessor-edition_2023)
  The assessor's rules and recommendations for rating each indicator. Use for: later, when ratings need to be defensible rather than plausible. Not yet read.

## Wisdom (Communities)

- [intacs: Gate4SPICE events](https://intacs.info/training-center)
  The assessor certification body runs regular, often free, online and onsite "Gate4SPICE" talks where practising assessors discuss the model's changes. Use for: testing whether a rating of rig would survive a real assessor's questions.

## Gaps

- No high-trust free source yet on how assessors treat tool-enforced process (a harness like rig) versus a written process description at PA 3.1.
