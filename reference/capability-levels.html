Capability levels, attributes and the rating rule

The grid

Process dimension (PRM): which process is assessed, e.g. MAN.3. Each process has a purpose and outcomes.

Capability dimension: levels 0–5, each made of process attributes (PAs), each PA rated N/P/L/F.

PAM = PRM + indicators (base practices, generic practices, information items). Result: one level per process.

WHAT · HOW · DOING

WHATgoals and outcomes: the PAM
HOWmethod, tools, lifecycle: e.g. Scrum, Jira workflow
DOINGone performance: a sprint, a PR, a release

The assessor maps the HOW and DOING onto the WHAT. The PAM prescribes no order and no document structure.

The level rule

Level n: every PA at level n is L or F, and every PA below level n is F.
