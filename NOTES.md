# Notes

- The whole course was requested at once, built on the 80/20 principle: the shortest path to being well versed. Lessons therefore carry their own spacing: most open with a warm-up retrieving earlier lessons, and the capstone and the red-pen lesson interleave everything.
- Examples use one running fictional project, **the Seat-Heat team**: eight people at a Tier-1 supplier building seat-heating control software for an OEM, working in Jira, Git, pull requests and CI. From lesson 14 on, their company bids to deliver the whole seat-heating ECU, so system-level examples use that ECU (not the seat: an ECU has no direct end-user interface). Keep every example inside that project so later lessons can reuse it.
- Learners include teams that build or use automated engineering tooling and AI agents; lessons 10–16 serve them. Keep every lesson generic: no real company, product or tool names.
- The workspace lives at `D:\learn\aspice` and is published at <https://hugoforte.github.io/learn-aspice/> (repo `hugoforte/learn-aspice`, Pages from `main`).
- Neither the PAM nor the Guidelines may be redistributed: link with `#page=N`, quote only short phrases. PAM PDF pages equal printed pages; the Guidelines PDF page is the printed page + 2.
- `assets/quiz.js` shuffles answer buttons except ordered scales (N/P/L/F, digits, a/b/c). Still balance keys by content: mix Yes/No, Right/Wrong, Credits/Ignores and N/P/L/F answers.
- Each lesson has an Anki deck in `anki/` with the lesson's file name, linked under its "Your win" box. The files use Anki's text-import headers (pipe separator, HTML, Basic note type, one subdeck and tag per lesson) and a stable GUID column, `aspice-LL-NN`, so re-importing updates cards in place: never renumber a GUID, only append. Use curly quotes, since a straight double quote at the start of a field is read as CSV quoting, and avoid `|` and `&`. Cards paraphrase the lessons and cite by page; when a lesson's content changes, change its deck in the same commit.
- `anki/aspice-4.1.apkg` is built from those text files by `python anki/build.py` and committed, because Pages serves the repo as is. Rebuild it in the same commit as any deck change. The script needs Anki's own Python package (`pip install anki`, in a throwaway venv): it runs Anki's real importer, so the package matches a text import card for card. That dev-only dependency is worth it over `genanki`, which would reimplement the format.
- Open lessons with `Start-Process <path>` from PowerShell.
- `CONTEXT.md` is the canonical vocabulary: one definition per term, the words to avoid, and the page that teaches it. `reference/glossary.html` is the learner's copy of its ASPICE terms. Change a term in both in the same commit, and use the settled word in lessons, sheets and decks.
