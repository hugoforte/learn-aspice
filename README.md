# Learning Automotive SPICE through rig

A self-paced course on the Automotive SPICE 4.1 process assessment model, taught by using its capability model as a mirror on [rig](https://github.com/hugoforte/rig)'s own way of working.

## Contents

- [MISSION.md](MISSION.md): why this course exists and what success looks like
- [RESOURCES.md](RESOURCES.md): the sources lessons draw on
- `lessons/`: one self-contained HTML lesson each, with interactive practice
- `reference/`: printable quick-reference sheets
- `learning-records/`: what has been learned, used to pick the next lesson
- `assets/`: the stylesheet and quiz component every lesson shares

Open a lesson file in a browser to take it.
